# M1 二维轴对称流动

本阶段扩展静态诊断，支持受控二维轴对称直圆管的已核验边界配置。样例不求解，检查不修改源模型；开发样例和隐藏窗口验证不等于专业复核或用户人工验收。

## 支持与边界

| 项目 | M1 范围 |
|---|---|
| 组件、研究、材料 | 米制二维轴对称、单流体域、单一定常研究；牛顿流体密度和动力黏度从唯一有效材料读取 |
| 几何 | 通过坐标、边界采样及域邻接证明 r=0 轴线；通过轴对齐矩形的各条边证明直圆管半径与直径 |
| 边界 | 法向速度入口、压力/无黏性应力出口、无滑移或滑移壁面、默认轴对称节点；显式和命名选择 |
| 数值 | 已求值常数的正值、入口方向及已核验无滑移直圆管的直径尺度 Re 筛查；滑移配置保留边界检查，跳过 Re |
| 不完整配置 | 未核验入口模式、嵌套/未知节点、缺坐标或拓扑证据时按规则记录跳过；独立材料结果仍可保留 |
| 封闭流动 | 不套用开口管必须有入口/出口的规则，明确标记未完成的适用性检查 |

不扩展瞬态、湍流、传热、三维、多域材料或 AI 推荐范围。包围盒只用于显示和基本范围核对，不能单独证明管径。Re 阈值仍是可配置筛查参数，不能证明转捩、收敛或物理正确。

## 契约与定位

原始 `inventory-0.2` 在轴对称几何下增加 `axisymmetric_evidence`，记录坐标名、顶点坐标、边界与顶点/域邻接及边界采样。不可读状态带原因；平面清单保持原有字段。

新轴对称归一化模型为 `diagnostic-0.2` / `axisymmetric-pipe-v1`；平面模型保留 `diagnostic-0.1`。外层继续使用 `diagnosis-0.2` 的实例、规则和节点覆盖，旧报告按原契约读取。新轴对称模型明确拒绝旧 AI 推荐。

Python 集成使用 `diagnose_inventory()` 生成完整报告。旧 `check()` 只保留平面兼容，收到轴对称模型时明确拒绝并指向新入口，避免返回缺少覆盖与来源的简版新契约报告。

桌面与导出报告展示组件、几何、物理场、节点及边界编号，概览使用 r/z 坐标并列出几何轴线。定位来自报告快照，不声称自动打开或选中 COMSOL GUI 节点。

## 规则

轴对称复用缺入口/出口、声明选择冲突、材料正值、入口方向、参数求值和 Re 风险规则，并新增：

- `AXIS_SELECTION_INCONSISTENT`：几何轴线与轴对称条件/显式其他角色的选择不一致，给出核对轴线条件和选择的建议。
- `EMPTY_BOUNDARY_SELECTION`：启用节点的实际生效选择为空，提示核对空选择或节点覆盖；默认回退节点按 COMSOL 实际行为处理。

默认 `AxialSymmetry` 的声明选择可能是全部边界，而实际仅在 r=0 生效。这不是与全部入口/出口冲突的证据。角色冲突区分声明意图和有效选择，使用 Warning 提示人工核对，不把 COMSOL 的节点覆盖行为当作必然物理错误。

缺入口/出口规则只在几何和已核验端口模式支持开口圆管判断时执行；没有任何端口时不能猜测用户是否要建立开口管。未知耦合仍阻断依赖流动语义的规则，独立材料常数检查保留。

## 复现

生成受控轴对称模型并各重复读取三次：

```powershell
python scripts/verify_m1_api.py --comsol-root '<COMSOL_ROOT>' --write-fixture
```

脚本仅在新 `outputs/m1_api/<运行时间>/` 保存样例、原始清单、命令和日志；核对原模型哈希，检查样例没有解序列。默认轴节点编辑受 COMSOL 管理，实测不可执行的故障操作保留在本地失败日志，不能伪造对应 API 成功证据。

对生成的任意 `.mph` 可使用既有桌面或命令行只读入口。消费者复核和原平面回归分别使用 `scripts/verify_m1_consumers.py`、`scripts/verify_m1_regression.py`，参数见各脚本 `--help`。消费者脚本明确区分新 CLI 报告、真实 API 清单的离线回放及历史报告。

全量测试：

```powershell
python -X utf8 -m unittest discover -s tests -v
```

M0 的三份历史摘要原样保留，绑定冻结提交 `21b2851` 的源码身份；M1 使用单独证据，不修改旧指纹来适配新程序。
