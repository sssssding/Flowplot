## 发现与未完成项

1. 入口和出口节点有 COMSOL 弃用警告：当前旧特征将在后续版本停止使用，界面建议使用物理场边界栏中的新入口/出口特征。此提示不是入口缺失、选择冲突或求解失败。当前模型已在 6.3.0.290 求解；若迁移新特征，应另建副本、重新枚举属性并重跑回归，不能静默替换已有证据。
2. 保存模型的结果树包含解数据集和数值派生值，但没有速度云图图组。本轮没有新增图组；速度云图复核仍未完成，不能用几何高亮代替云图验收。
3. 切换到 `missing_inlet.mph` 时出现“是否保存基准模型更改”的提示，当前停留在该提示，没有选择保存或丢弃。尚未通过 GUI 打开任何异常样本。窗口查看状态是否丢弃需由用户确认。
4. 五个异常文件的磁盘 SHA-256 与 manifest 一致；该检查不是 GUI 核对，也不改变专业标签审核状态。
