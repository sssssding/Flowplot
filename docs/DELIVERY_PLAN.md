## 实现方每轮交付格式

每次只推进一组相关任务，更新本表状态并在 PROGRESS.md 记录：

1. 本轮完成的任务 ID、改动文件及用户可观察的行为。
2. 实际验证命令、运行环境、通过/失败/跳过数量；区分模拟、离线 fixture、真实 COMSOL、隐藏窗口及可见人工检查。

4. 尚未满足的要求、原因和下一步；没有结果的项目保持待办。
5. 策划复核结论留待独立检查，不能由实现方自行填成“策划已通过”。

策划收到交付后，应核对实际改动并重跑相关验证。出现可复现缺陷则附触发条件、预期/实际结果和证据，退回对应任务；相关验证通过后再推进下一项。
