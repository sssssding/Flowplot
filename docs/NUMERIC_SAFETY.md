# 诊断数值稳定性

这轮修复规则计算的数值边界，不扩大 COMSOL 几何/物理场支持范围，不自动修改参数，不调用求解器，也不意味着完成专业或独立验收。

## 发现的问题

旧实现按普通浮点乘除顺序计算 `rho × abs(Uin) × H / mu`。各输入均有限，也不能保证中间乘积有限或非零：

- 构造 `rho=1e-200`、`Uin=1e-200`、`H=1e200`、`mu=1e-210`，应得到名义 Re `1e10`；旧中间乘积下溢为零，未报告风险。
- 构造 `rho=1e200`、`Uin=1e200`、`H=1e-200`、`mu=1e200`，应得到名义 Re `1`；旧中间乘积溢出为无穷大，错误报告风险，且无法保存合规 JSON。

这些是 Python 构造的极端数值反例，不是真实 COMSOL 模型或合理物性建议。它们用于验证程序不会因计算顺序给出错误结论。

## 新行为

先以已记录数值的十进制文本构造精确分数，合并完整比值，最后才舍入到报告使用的浮点数。这里处理的是 COMSOL 已提供的数值，不执行原始表达式，不重新做单位转换，也不增加物理有效性判断。

真实 [变体回归](REGRESSION_FAMILY.md) 暴露了末位阈值噪声：名义 Re=2000，API 高度 `0.05000000000000001 m` 导致 Re=`2000.0000000000005`。比较现要求 `Re > threshold` 且超出量大于 `4 × math.ulp(float(threshold))`；默认阈值 2000 对应约 `9.09e-13`。保护带内不报 Re 风险，但原始尺寸/数值不改、不四舍五入。这不是物理安全裕量、误差估计或转捩结论；极小次正规阈值也按绝对 4 个间距处理，非相对容差。报告记录 `numeric_policy.reynolds_threshold_guard_ulps`，报警证据另含 `numerical_comparison_margin`，中文报告说明比较策略。

- 最终值可表示：正常检查，避免中间乘积造成的溢出/下溢。
- 最终正值超出非零有限浮点表示范围：报告 `EVALUATION_UNAVAILABLE` / Warning，整体 `partial`；保留入口节点、边界、计算量、原因、公式、四个操作数和阈值。不写入无穷大，也不把下溢值写成零或正常工况。
- 真正的零入口速度：仍按 `INLET_DIRECTION` 提醒，不误当作计算不可用。
- 非正材料参数：仍按原规则报告并跳过 Re，不进行除零。
- 输入 NaN、无穷大、不能用有限浮点表示的整数：拒绝作为有效数值证据；不能形成干净诊断。布尔值、字符串或超大整数也不能用作数值选项。
- 有限包围盒坐标相减后尺寸溢出：返回超出支持范围，不使用无穷大尺寸检查。

`EVALUATION_UNAVAILABLE.evidence.quantity` 为 `reynolds_height_based` 时，`reason` 分为 `above_float_range` 和 `below_nonzero_float_range`。此时不提供虚构的 Re 数值。其他已完成的规则结果（例如负速度方向提醒）保留，但整份报告不能作为完整检查计分。

## 入口与旧报告

单文件、桌面、批量入口使用一致的有限数值选项验证，错误选项在启动 COMSOL 前拒绝。离线对比遇到无效阈值返回不可比较；分享旧报告时不补造无效配置。概览遇到无效数值证据显示不可用，部分报告提示派生量也可能未完成。

规则源码指纹已变化。旧报告可以保留为历史记录，但不能与新版报告直接比较，也不能在当前规则批量评估中作为匹配来源计分。应重新检查，不修改旧指纹。源模型和旧运行目录保持不变。

## 验证

```powershell
python -X utf8 -m unittest discover -s tests -p test_numeric_safety.py -v
python -X utf8 -m unittest discover -s tests -q
```

数值专项 22 项测试加一项单文件流水线测试，覆盖中间与最终溢出/下溢、零/负速度、非正材料、最小正次正规值、最大有限浮点数、阈值两侧及 4 ULP 边缘、量级缩放、超大整数、各入口选项、JSON 保存、部分报告展示/评分及输入不变。

真实回归包含原六个受控 MPH，以及新生成的 14 个矩形变体，各加载两次；基准和缺少入口另行完成真实桌面检查、取消、历史/对比/导出往返。隐藏窗口中另加两个**明确标为合成输入**的数值报告，核对未完成提示、证据、概览及分享重读；这部分不称作极端模型的 COMSOL 实测。可共享摘要继续保留专业审核和人工界面试用未完成标记。

## 回退

如需回退，应连同数值计算、派生量不可用处理和对应测试一起恢复，并重新生成匹配版本的真实证据。不要只替换指纹以复用旧报告；回退将重新引入上述已知漏报/误报与 JSON 保存风险。独立的有限输入检查可保留。
