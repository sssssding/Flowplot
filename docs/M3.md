# M3 三维与交付

本阶段将静态流动、传热和耦合检查迁移到受控三维直圆管及带固体管壁样例。模型构建与检查均不运行网格或求解器，开发样例不能作为独立准确率或物理正确性的证明。新增能力仍需用户人工验收。

## 支持矩阵

| 项目 | 二维轴对称 | 三维 |
|---|---|---|
| 流道几何 | M1 已核验的单域直圆管；M2 多域流动保留几何规则跳过 | 以实际流体域、圆柱构建证据、面采样和邻接关系核验直圆管；不从全模型包围盒推断流体管径 |
| 端口与壁面 | 入口、出口、壁面及 r=0 轴线 | 入口/出口端面与侧壁面；三维没有轴线边界条件 |
| 材料与工况 | 已解析常量正值、正常速度入口及已核验管径下的 Re 筛查 | 复用相同证据前提，材料只绑定实际流体域 |
| 热材料/边界 | 标量热常数、温度与通用内向热流节点、流固热域 | 按三维域和二维面核验同一规则集合 |
| 流热耦合 | 引用、启用状态、共同域和唯一稳态研究参与 | 按三维域核验引用与选择，缺证据保留跳过 |
| AI 推荐 | 继续限定原二维矩形模型族 | 明确拒绝，不增加训练或推荐支持范围 |

三维流动限 z 方向直圆柱及同轴管壁。曲管、任意旋转方向、湍流、瞬态、辐射、多相、结构力学、自动修改模型以及依赖解的能量守恒/收敛检查均未扩展。温度相关表达式、各向异性参数和未核验模式不判为模型错误，按规则记录部分覆盖。封闭流动不套用开口圆管必需端口规则；默认壁面覆盖未分配端面不自动构成面角色错误。

COMSOL `measureFinal` 的圆柱面积/体积实测存在约 0.51% 的近似误差，适配器对此采用 1% 一致性容差；坐标、曲率和法线仍按 `1e-7` 相对容差核验，不能用测量容差放宽形状证明。实际管径由圆柱侧面曲率提取并与域范围核对，避免原生包围盒的浮点偏差在 Re 阈值附近造成误报。Re 还要求每个有效端口只作用一个端面、入口出口完整配对、材料为已解析正值，以及完整无滑移侧壁。

## 契约与兼容

三维报告使用 `diagnosis-0.4 / static-3d-v1`，流动子模型使用 `diagnostic-0.3 / pipe-3d-v1`。面、域和来源证据随报告保存；旧 `diagnosis-0.1/0.2/0.3` 报告继续读取。M0/M1/M2 历史摘要保留原字节和当时源码身份，本轮另生成 M3 证据，不能手改旧报告指纹。

## 复现入口

```powershell
python scripts/verify_m3_api.py --comsol-root '<COMSOL_ROOT>' --write-fixture
python scripts/verify_m3_consumers.py --help
python scripts/verify_m3_demo.py --help
python scripts/verify_m3_regression.py --help
python -X utf8 -m unittest discover -s tests -v
```

每次运行使用新输出目录。API 验证要求每个真实样例连续读取三次、没有解序列，并核对原模型未变。消费端验证涵盖中文报告、隐藏 Tk 展示、组件/接口/节点/面定位、历史、报告包、对比和推荐隔离。

三轮自动演示与用户可见演示分开记录：自动工程验证不代替用户操作、专业复核或人工界面验收。

演示脚本的 `--write-fixture` 采用独占创建，保留已有摘要。重复演示可省略该参数，在新输出目录核对 `summary.json`；需要发布新的开发摘要时，先归档旧本，再发布已核对源码、模型和九项结果的完整摘要。不能只改指纹升级旧记录。
