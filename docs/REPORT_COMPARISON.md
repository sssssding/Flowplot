# 前次 / 本次检查报告对比

用于修改模型后的复查或团队讨论：对比两份已经生成的单模型检查报告，不加载 `.mph`，不调用 COMSOL、不运行求解器、不修改输入报告。仅比较诊断条目，不枚举所有模型参数变化，也不证明修复成功。

## 桌面操作

1. 正常检查模型，或点击“读取已有报告”展示**本次**报告。
2. 点击“与前次报告对比…”，选择含 `run.json`、`diagnosis.json` 的**前次**报告目录。
3. 在独立对比窗口查看差异或无法比较的原因；可点击“保存本次对比…”选择保存位置。

导出时新建随机标识的 `comparison-...` 子目录，写入 `comparison.json` 和中文 `report.md`，不覆盖已有结果。运行中和没有有效报告时，对比按钮不可用；对比失败不清除当前已经核验的单模型报告。保存失败会明确提示，不能当作已导出。

## 命令行

```powershell
python src/flowpilot/compare_reports.py outputs/check/before-001 outputs/check/after-001 --output-dir outputs/comparisons/run-001
```

前两个参数依次为前次、本次单模型报告目录，不是模型路径或整组汇总目录；输出目录必须尚不存在。不需要 COMSOL 安装或许可证，但仍需项目 Python 依赖。

退出码：`0` 表示完成可比较报告的差异分析，**不是修复通过**；`2` 表示报告不满足直接比较条件，仍输出阻断原因；`1` 表示输入、完整性或文件操作失败。

## 比较条件与口径

两份报告先通过已有报告读取器的完成状态、来源标识和诊断内容哈希检查。失败、取消或内容被改动的报告直接拒绝。

直接比较还要求：两份诊断均为完整 `checked`，规则源码哈希相同、模型读取源码哈希相同、COMSOL 版本相同、检查模板相同、有效且相同的 Re 筛查阈值。缺少来源字段、`partial` / `unsupported` 或配置不一致时，状态为 `not_comparable`，差异计数为 `null`，不输出新增/消失结论。源码哈希只核对报告声明，不能证明签名或完整执行环境一致。

比较结果按“规则 code + 排序后的节点标识 + 排序后的边界编号”分组：

- **本次新增报告**：仅本次存在该组。
- **本次未再报告**：仅前次存在该组，不命名为“已修复”。
- **等级、解释、证据或条目数量变化**：两次都有该组，但内容不同。
- **报告条目相同**：两次同组内容相同。

同组重复条目保留，不去重；显示的数量为组数，不是模型数、问题严重度评分或质量提升幅度。改变节点名或边界编号会按不同组处理，不自动推断它们是同一几何实体。两份报告没有诊断条目也不代表模型参数没变。

两边模型 SHA-256 可以不同，这是修改后复查的常见情况；但工具无法确认所选文件真的是同一个模型的前后版本，界面和报告都会提醒人工确认。对比反向选择会交换新增和未再报告，必须注意顺序。

## 输出、隐私与验证

`report-comparison-0.1` 摘要保留两边模型文件名/哈希、检查记录与诊断内容哈希、规则/读取源码哈希、COMSOL 版本、阈值、比较条件和前后条目。不会主动复制本机绝对路径、日志、模型副本或未知来源字段；证据和模型文件名仍可能含项目敏感信息，分享前需审阅。源码哈希和文件哈希不是数字签名。

新增 21 项离线测试，覆盖四类差异、重复条目与不同边界、不受条目顺序影响、来源/阈值/模板不符、不完整或损坏报告、输出不覆盖、隐私字段、CLI 退出码及界面取消/失败路径。

真实隐藏窗口验证在 COMSOL 完成基准与缺少入口两次检查后，实际触发对比按钮、构造对比窗口并导出报告：正向新增一组 `MISSING_INLET`，反向未再报告一组。它们是两个受控开发样本，用于验证差异功能，**不是实际修复实验、专业验收或新用户试用**。证据保存在 [桌面验证摘要](../data/fixtures/desktop_smoke.json) 的 `report_comparison` 中。

## 影响与回退

仅新增离线对比模块、桌面按钮和对话框，未修改规则、解析、诊断契约或原始模型。回退时撤回对比模块与桌面对比入口；单模型检查和批量评估仍可独立使用。
