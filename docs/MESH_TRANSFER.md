## 当前实施选择

不伪造缺失的自由度/网格质量特征，也不将几何距离解释为网格相同。现阶段采用明确的迁移约束：

- 便携推荐仍是实验候选，必须在目标模型的独立副本验证；不会自动修改模型、网格或启动求解。
- 候选与默认比较时，保持该目标的网格、物理、边界不变，先检查守恒、壁面/速度、压降及参考漂移；任何质量失败不能由速度收益覆盖。
- 换网格、版本或硬件都不能直接复用旧耗时结论。已知严格参考失败文件不能靠相近特征获得推荐。
- 界面和导出结果明确标记 `mesh_features_available=false` 并说明限制；标记只表示没有采集网格特征，绝不表示已检查或通过网格质量。

这项说明不会新增拒绝几何类型、调整距离阈值、改变候选排序或缩小既有支持范围；正式 T13 指标及独立模型要求保持原样。

## 数据契约与后续方案

本次不改变 `.mph` 解析、统一模型 Schema、学习文件或正式冻结集合。推荐 0.2 结果只增加解释性字段：`training_coverage`、`mesh_notice`、`selection_basis`；几何/工况覆盖来自已核验的训练数据。`ranges.log10_aspect_ratio` 明确存储 log10(L/H)，界面转换为长宽比，极端值以 10 的幂显示，避免引入溢出/下溢。

若以后增加网格感知，需先从真实 API 采集元素/自由度、尺寸或质量证据，明确无网格/未求解/不同单元阶次的缺失语义，版本化契约，并用同几何不同网格的多次实测验证；不能从文件大小、名称或图片估算为已核验特征。当前未实现这项后续能力，不将方案文档当作功能完成。
