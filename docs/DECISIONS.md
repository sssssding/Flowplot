# 技术决策记录

## D-005：提前交付受限的本地参数推荐原型

- 日期：2026-10-14；按用户要求优先实现 AI 推荐并快速检验后收尾。
- 决策：新增本地 kNN 对数耗时回归与明确触发的基准副本校准，先比较四种稳态相对容差/线程数组合。推荐只展示、没有自动应用；未知模型、机器或不完整/异常诊断拒绝推荐。
- 影响：新增 `FlowPlotAI.cmd` 复用旧检查窗口，旧入口、规则、原模型及历史证据不变。不是通用模型推荐或独立性能通过；专业审核及 T13 原正式性能门槛继续保留。具体命令与回退见 `AI_RECOMMENDATION.md`。

## D-001：第一版限制为二维稳态层流

- 日期：2026-10-11
- 状态：已采纳
- 决策：MVP 仅支持二维、单流体域、Laminar Flow、Stationary，以及 Inlet/Outlet/Wall。
- 原因：先验证完整、可重复的解析与诊断闭环，避免范围扩张掩盖基础可靠性问题。
- 影响：3D、湍流、瞬态与多物理场模型必须明确报告“不支持”。

## D-002：采用 COMSOL Java API 作为首选解析入口

- 日期：2026-10-11
- 状态：已采纳，待技术验证
- 决策：先使用 COMSOL Java API 读取模型结构，再按需封装为 Python 服务。
- 原因：直接访问 COMSOL 模型树与 feature 参数，避免让 AI 猜测二进制文件内容。
- 影响：开发与 CI 环境需要记录 COMSOL/Java 版本及许可条件。

## D-003：规则负责结论，AI 负责解释与后续推荐

- 日期：2026-10-11
- 状态：已采纳
- 决策：入口/出口缺失、冲突、方向等确定性问题由规则引擎判定；生成式模型不得覆盖规则证据。
- 原因：提高可解释性、可验证性和比赛展示可信度。
- 影响：所有诊断必须关联规则 ID 与结构化证据。

## D-004：先提供保守的矩形通道诊断配置

- 日期：2026-10-11。
- 状态：实现中，专业审核与独立验收待完成。
- 决策：首版仅验证自建矩形模型族；模式、材料来源和单位求值均需有 API 证据，不确定时返回不支持或检查不完整。
- 原因：COMSOL 保存的默认属性并不一定在当前模式生效，声明选择也不等于有效选择。
- 影响：默认 Wall 覆盖不报冲突；不同显式角色重叠只提示人工核对；高度尺度的 Re 默认 2000 是可配置筛查阈值，不是普适转捩判据。
