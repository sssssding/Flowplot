# 技术决策记录

## D-001：第一版限制为二维稳态层流

- 日期：2026-10-11
- 状态：已采纳
- 决策：MVP 仅支持二维、单流体域、Laminar Flow、Stationary，以及 Inlet/Outlet/Wall。
- 原因：先验证完整、可重复的解析与诊断闭环，避免范围扩张掩盖基础可靠性问题。
- 影响：3D、湍流、瞬态与多物理场模型必须明确报告“不支持”。

## D-002：采用 COMSOL Java API 作为首选解析入口

- 日期：2026-10-11
- 状态：已采纳，待技术验证
- 决策：先使用 COMSOL Java API 读取模型结构，再按需封装为 Python 服务。
- 原因：直接访问 COMSOL 模型树与 feature 参数，避免让 AI 猜测二进制文件内容。
- 影响：开发与 CI 环境需要记录 COMSOL/Java 版本及许可条件。

## D-003：规则负责结论，AI 负责解释与后续推荐

- 日期：2026-10-11
- 状态：已采纳
- 决策：入口/出口缺失、冲突、方向等确定性问题由规则引擎判定；生成式模型不得覆盖规则证据。
- 原因：提高可解释性、可验证性和比赛展示可信度。
- 影响：所有诊断必须关联规则 ID 与结构化证据。
