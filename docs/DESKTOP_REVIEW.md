# 可见桌面工程核验（2026-10-12）

负责人：Codex；分支 `feat/local-acceptance`。这是编码代理的可见窗口工程检查，不是未参与开发的新用户、独立验收或 COMSOL 专业审核。

## 本轮修改

1. Windows 启动器支持 `FLOWPILOT_PYTHON`，依次回退到 `.venv`、系统 Python。标准库启动检查在缺少 jsonschema / tkinter 时给出明确提示，不自动安装、下载或替换环境；`--check-env` 不启动窗口或 COMSOL。
2. 原默认布局把空表格留成五行，模型来源显示后证据区几乎只剩一行。调整为屏幕适配的初始窗口、三行表格及可拖动垂直分隔，优先保留证据阅读空间。
3. 隐藏窗口集成入口新增 `--model-root`，用独立、清单匹配的原件复现，避免为了测试而恢复或覆盖工作区里的修改。

## 真实可见核验

- 旧窗口最小化及用户输入标记曾阻挡恢复；用户随后明确同意操作，新启动窗口成功前置并读取。没有通过旧窗口的异常状态推断测试成功。
- 从可见按钮启动基准原件副本检查，重复加载两次，约 45 秒完成；正确显示“当前规则未发现问题”，模型名与哈希可见，不显示物理通过结论。此项发生在布局修改前。
- 布局修正后从可见按钮启动缺少入口副本检查，重复加载两次，约 26 秒完成；显示 Critical 的“缺少有效入口”、模板适用范围、核对建议及空入口证据。
- 实际拖动分隔条，证据空间随之增加；查看模型概览并滚动，核对通道 1 m × 0.05 m、密度 1000 kg/m³、动力黏度 0.001 Pa·s、出口声明/生效边界 4。
- 通过“读取已有报告”选择既有重叠样本报告，显示重叠风险及有效入口缺失两条诊断。先扩展表格，再分别查看详情：入口被覆盖不是两个条件同时生效，节点为 inl1 / out_conflict，相关边界 1。
- 系统目录对话框的焦点文本曾与截图不一致；以实际输入框光标和输入后的可见路径核对，未在搜索框提交路径，也未操作第三方服务。

可见检查只加载副本，不调用求解或保存模型。用户修改版基准的 SHA-256 仍为 `e43ead4f16b18d90a77f07da0381b7ece4fb9dcd5f1efb08b67b1d221245dac9`；原件副本仍与 manifest 一致。
