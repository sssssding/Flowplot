# 模型概览与缺失边界证据

用于理解“工具实际上读到了什么”，而不只看规则结论。概览来自已经核验的 `diagnosis.json` 中的归一化模型快照，不额外加载 `.mph`、不执行表达式、不运行求解器。

## 桌面操作

完成模型检查，或读取/从历史打开已有报告后，在结果区切换“问题诊断”和“模型概览”页签。概览为只读文字，包含：

- 当前检查模板、组件、物理场和研究标识、报告中的 COMSOL 版本。
- 米制轴对齐矩形的 x 向尺寸 L、y 向尺寸 H；不推断其他几何或流向。
- 密度、动力黏度的原始表达式、单位和 API 求值。
- 启用且进入当前模板的边界节点、模式、声明边界、实际生效边界、显式/回退选择性质。
- 法向入口速度或出口压力的表达式、单位和 API 求值，以及各角色实际生效的边界编号集合。

例如已验证基准的边界关系：

| 角色 | 声明边界 | 实际生效边界 |
|---|---|---|
| 入口 | 1 | 1 |
| 出口 | 4 | 4 |
| 全边界回退壁面 | 1、2、3、4 | 2、3 |

回退壁面的声明包括入口和出口，不等于它仍在这两处生效；不能把这张表中的声明重叠直接判作边界冲突。API 编号不是几何位置示意图，节点/编号改动后的实体对应仍需在 COMSOL 中核对。

## 不可用与未求值

超出模板、没有归一化模型的旧报告、证据结构错误或模板不一致时显示“模型概览不可用”，不补造空模型或默认参数。原有诊断仍可按自己的完整性条件查看。

`partial` 报告可以查看已有证据，但明确提示部分检查未完成。参数 `unresolved` 显示未求值，不显示成 0；非正材料值按原证据展示，不自动纠正，是否触发规则以诊断页为准。声明边界 `null` 显示“无法读取”，空列表显示“空选择”，二者不混同。

概览不是实时 COMSOL 模型树，不包含未启用节点或所有原始属性。未列出某节点不代表该节点已从模型中删除；数值格式为便于阅读的九位有效数字，完整精度仍在 JSON 证据中。概览不代表物理正确、求解收敛或专业验收通过。

新检查开始、失败或取消时不保留上一份概览，避免把旧模型资料当成本次结果。

## 缺少入口/出口的具体证据

`MISSING_INLET` / `MISSING_OUTLET` 的判定条件、code 和等级不变，现在额外保留：

- `required_role`：要求存在的入口或出口角色。
- `observation_scope`：仅观察启用且已归一化的边界节点。
- `active_role_node_count` 和 `effective_boundary_ids`：该角色启用节点数、空的有效边界集合。
- `absence_kind`：`no_enabled_role_node`（没有启用的该角色节点）或 `all_effective_selections_empty`（节点存在但有效选择全空）。
- `active_boundary_nodes`：当前所有启用边界节点的角色、声明/实际生效边界和选择性质，按标识排序。

有效选择为空但节点仍存在时，finding 的相关节点保留其标识；不猜测应该把入口/出口放到哪条边，边界编号保持空。没有启用节点不区分“节点已删除”和“节点被禁用”，需要结合原始模型人工核对。

规则源码哈希因证据增强而变化：历史报告仍可按原条件查看，但旧报告与新报告不能直接跨版本对比，批量离线评估也会拒绝旧规则来源。需要重新检查获得当前版本证据，不能手工补造哈希。

## 验证与回退

新增 12 项概览测试、4 项缺失证据测试，总计 184 项测试通过。覆盖六个真实 fixture、声明/生效选择差异、未求值、材料原值、不可用旧报告、异常证据、空/未知选择、输入不变和旧概览清理。

COMSOL 6.3.0.290 上重新对六个开发模型各加载两次，规则 code 集合仍全部匹配；基准与缺少入口另做真实桌面隐藏窗口检查，验证页签切换、只读文字、基准 1/4/2、3 生效边界和缺少入口的非空证据。回归摘要更新至 `batch_regression.json` 和 `desktop_smoke.json`，原模型哈希不变。这不是专业审核或独立 Recall 验收。

撤回概览模块、结果页签及缺失规则证据字段的补充即可回退；未改变解析源码、归一化 Schema、规则判定范围或原始模型。报告的既有 JSON 版本保持不变，新增证据为原 `evidence` 对象内的字段。
