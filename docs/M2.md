# M2 流动与传热耦合

本阶段新增独立传热模块与非等温流耦合模块，通过注册表接入现有诊断和通用报告界面。检查只读取模型副本，不修改源模型、不生成网格或运行求解。受控样例是开发验证集，专业复核和用户人工验收仍需另行完成。

## 支持与跳过

| 项目 | M2 范围 |
|---|---|
| 真实接口 | COMSOL 6.3 的 `HeatTransferInFluids`、`HeatTransfer` 与 `NonIsothermalFlow` |
| 热材料 | 按实际域选择检查材料覆盖、已解析标量密度/定压热容/导热率的正值；保留表达式、单位、求值状态和来源 |
| 热边界 | 已启用温度和通用内向热流节点的有效空选择、同一热接口显式声明选择重叠；区分声明与实际生效选择 |
| 对流关联 | 区分给定速度与同组件流场速度；核对引用域及稳态研究参与；缺少显式耦合节点本身不判错 |
| 显式耦合 | 接口引用、启用状态、共有流体域与研究参与；未知接口类型及分步研究保留待复核 |
| 共轭样例 | 二维轴对称流体域与固体管壁、两种材料；分别检查热材料和流固域模型的有效选择 |
| 多域流动 | 保留独立材料、已核验端口参数及选择检查；未证明单个流体域的圆管几何，入口/出口必需性、轴线角色及 Re 规则明确跳过 |

温度相关材料表达式、各向异性导热张量、未核验热流模式和未知嵌套节点不能当作模型错误，也不能当作完整检查。流动壁面与热边界位于同一边界是正常配置，不跨物理场报告选择冲突。默认绝热、轴对称以及系统管理的节点按实际生效证据处理。

静态检查不证明能量守恒、求解收敛或物理正确性；不扩展瞬态、湍流、辐射、三维或 AI 推荐支持范围。共轭样例的热域检查通过不意味着多域流动全部规则均已完成。

## 规则与契约

| 模块 | 规则 |
|---|---|
| heat | `HEAT_INVALID_MATERIAL_PARAMETER`、`HEAT_MATERIAL_COVERAGE`、`HEAT_EMPTY_BOUNDARY_SELECTION`、`HEAT_BC_SELECTION_OVERLAP`、`HEAT_DOMAIN_CONFIGURATION`、`HEAT_ADVECTION_SOURCE` |
| thermal_coupling | `COUPLING_REFERENCE_MISMATCH`、`COUPLING_SELECTION_MISMATCH`、`COUPLING_PARTICIPATION_MISMATCH` |

新热报告使用 `diagnosis-0.3` / `thermal-static-v1`，物理场与耦合分别保留来源、规则覆盖、证据路径和中文建议。耦合来源使用 `coupling_tag`；热报告没有伪装成单一流动模型的顶层 `model`。旧平面/轴对称报告与历史 `diagnosis-0.1`、`diagnosis-0.2` 继续读取，新范围明确拒绝旧 AI 推荐。

原始 `inventory-0.2` 采用可选的热证据扩展：接口域选择与逐研究步骤参与、热节点属性和递归子节点、热材料常数及不可读原因。非热模型保留原采集语义。引擎指纹包含所有规则模块与契约；M0/M1 历史摘要原样保存，使用其记录时的来源清单验证身份，不改旧指纹。

未知耦合仍按作用域阻断依赖规则。已识别耦合只有在其默认模式、引用/研究、流体域和常量材料证据全部满足已核验前提时才解除阻断。合法局部耦合不当作选域错误，其未耦合区域语义仍待核验。

[COMSOL 6.3 流动与传热关联说明](https://doc.comsol.com/6.3/doc/com.comsol.help.heat/heat_ug_modeling.06.29.html)列出多种耦合方式；具体字段及默认行为以本阶段实际 API 清单为依据。

## 复现

```powershell
python scripts/verify_m2_api.py --comsol-root '<COMSOL_ROOT>' --write-fixture
python -X utf8 -m unittest discover -s tests -v
```

每次只创建新的 `outputs/m2_api/<时间>/`。真实完整清单和摘要分别保存为 `data/fixtures/m2_inventories.json`、`m2_api_evidence.json`。每个样例重复读取三次并检查无解序列，运行前后核对原六模型哈希。

`scripts/verify_m2_consumers.py` 对真实清单进行明确标记的离线回放，再验证隐藏 Tk 展示、来源定位、历史、报告包往返、对比和推荐隔离；不冒充新 COMSOL 运行或可见窗口验收。`scripts/verify_m2_regression.py` 将六份当前源码下的真实 CLI 清单与十四份历史清单和固定旧基线比较；参数见各脚本 `--help`。

## 验证记录

COMSOL `6.3.0.290` 最终输出为 `outputs/m2_api/20261018-214634/`。17个未求解样例各完整读取3次一致，所有样例均无解序列；原六模型哈希前后不变。加热流体圆管半径0.025 m、长度1 m；共轭样例增加0.005 m厚固体管壁，两个域分别使用独立材料。全部样例均为开发验证，不作为独立准确率或专业验收结论。

| 样例 | 检查状态及发现 |
|---|---|
| normal | `checked`，流动/传热/耦合三模块全部执行，无发现 |
| invalid_k / invalid_cp | `partial`，`HEAT_INVALID_MATERIAL_PARAMETER`；未满足耦合材料前提的依赖规则跳过 |
| invalid_rho | `partial`，热材料与流动材料两项非正发现 |
| missing_k / temperature_dependent_k / anisotropic_k | `partial`，未求值、非恒定或非标量参数保留证据缺口，不判为模型错误 |
| empty_heat_flux | `checked`，`HEAT_EMPTY_BOUNDARY_SELECTION` |
| thermal_overlap | `checked`，`HEAT_BC_SELECTION_OVERLAP`；按实际有效选择没有额外空选择发现 |
| disabled_coupling | `checked`，禁用耦合不阻断已明确的手动速度关联，无发现 |
| disabled_heat_interface | `partial`，`COUPLING_PARTICIPATION_MISMATCH`，启用耦合仍引用已禁用热接口 |
| inactive_heat_study | `partial`，研究参与未核验；允许合法分步研究，不报为模型错误 |
| legal_manual_velocity / legal_prescribed_velocity | `checked`，无显式耦合节点仍可确认手动关联/给定速度，无发现 |
| legal_convective_flux | `partial`，当前热边界冲突规则未核验该模式，无发现 |
| conjugate_normal | `partial`，热与耦合检查完成；多域流动保留独立检查，几何依赖规则跳过，无发现 |
| conjugate_missing_wall_k | `partial`，固体导热参数缺证据；已检查流体材料，缺失值不填0或判非正 |

默认热域内的 `Opacity` 子节点实测为禁用。递归采集后，规则仅接受数量匹配、全部读取成功且禁用的子树；启用或不可读子节点仍跳过。`NonIsothermalFlow` 的域选择由 COMSOL 管理，直接编辑空/错误域被拒绝，相应失败日志保留；选域故障仅用明确标记的单元反例覆盖，不冒充成功构建的实模。

`m2_consumer_smoke.json` 记录42份报告隐藏 Tk 验证：17份真实M2清单的离线回放、6份旧 `diagnosis-0.1`、6份M0与13份M1 `diagnosis-0.2`。选中问题行核对组件/接口或耦合/节点/实体来源，历史、包往返、自对比与旧推荐隔离均通过。输出为 `outputs/m2/consumer-verified-local/`；不等于可见界面或用户验收。受限环境不能初始化本机 Tk，最终验证使用本地获准执行。

最终六平面模型各新读3次，输出 `outputs/m2/planar-six-verified/`，6/6完整检查且code集合匹配。`m2_planar_regression.json` 记录20/20与固定基线 `1241c27` 的诊断payload一致，其中十四份为历史真实清单回放，未宣称全部是本轮实读。中途源码发生修复的首次六模型运行正确拒绝发布，保留在 `outputs/m2/planar-six-final/`，未计入最终通过结果。

正式文件入口另检查正常、负导热率、耦合引用禁用热接口、共轭正常四个 `.mph`，各读取3次。`outputs/m2/thermal-cli-verified/summary.json` 绑定当前引擎、报告与模型哈希，并确认源文件未变；它们是新的COMSOL运行，与上述离线消费回放分开记录。

非作者审查修复了未支持接口被误判为引用错误、合法局部耦合误报、重复证据路径、实体维度混用、多步骤研究参与证据和无契约热模型报告读取等缺口。研究相关规则按明确的启用Stationary步骤核对逐步参与；缺证据或分步求解不判为错误，独立材料/选择结果保留。
