## 可复现产品缺陷及修复

原 `RecommendationApp.open_report(directory)` 覆盖了基类的同名零参数方法。基类创建“查看完整报告”按钮时绑定 `self.open_report`，因此点击时会产生：

```text
TypeError: RecommendationApp.open_report() missing 1 required positional argument: 'directory'
```

修复为可选目录参数：零参数沿用基类打开当前 Markdown 报告；显式给出目录时保留共同读取器核验、旧结果清除、忙碌拒绝和 AI 预览，不绕过验证。

新 `test_recommend_report_button.py` 先复现两项错误，再通过全部五项回调契约测试。隐藏 Tk 流程实际调用 `report_button.invoke()`，只拦截外部查看器打开动作，确认目标是当前目录的 report.md；它不是模拟按钮绑定，也不是可见窗口点击。新记录 `ai_report_button_smoke.json` 明确 `report_button_default_viewer_mocked=true`。前六份 AI 记录保持原字节。
