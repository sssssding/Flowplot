# 可见界面验收与报告按钮修复

## 产品缺陷与修复契约

曾发现 `RecommendationApp.open_report(directory)` 覆盖基类同名零参数方法，导致“查看完整报告”按钮调用时缺少参数并触发 `TypeError`。修复后，零参数操作打开当前 Markdown 报告；显式目录操作仍走共同读取器校验，不绕过来源检查、旧结果清除或忙碌状态保护。

`test_recommend_report_button.py` 覆盖回调契约；`ai_report_button_smoke.json` 记录隐藏 Tk 实际调用按钮并验证目标报告。该测试用于功能回归，不证明可见界面可用。

## 当前可见记录

2026-10-17 人工记录见 [visible-ui-record.md](validation/2026-10-17/visible-ui-record.md)，涵盖正常检查、缺少入口、选择重叠、Re 风险、无效路径、取消/重试、历史、对比、报告包及推荐刷新/拒绝；真实范围外/部分模型仍未验证。用户反馈及截图位置保留在原记录，未改写成更高等级验收。其中“缺少入口”反馈写的是入口方向需要核对，不代表逐字确认诊断提示。

完整可见验收、新用户身份/计时、专业审核和独立模型集仍缺证据。自动化、隐藏窗口和单次操作记录不替代这些门槛。
