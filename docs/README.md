## 维护规则

- 代码、测试和必要文档在同一 Pull Request 更新；只改当前状态文档时不复制历史过程。
- 真实证据按来源、日期和哈希保留；失败、跳过及未验证项如实标注。
- 不记录令牌、许可证、私人日志或本机绝对路径。
