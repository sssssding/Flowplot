## 文档规则

- 文档与代码放在同一个 Pull Request 中同步更新。
- 设计变化必须说明动机、影响范围、验证方式和回滚方案。
- 不在文档中保存账号、许可证密钥、访问令牌或本机绝对路径。
- 进度只记录可验证状态；“进行中”必须关联 Issue 或负责人。
