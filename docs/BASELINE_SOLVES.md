# 基准模型的自动重复求解

日期：2026-10-11；负责人：Codex；开发分支：`codex/local-handoff`。

本入口用于验证已提交基准模型的自动求解稳定性，不是通用求解器，不运行五个异常模型，也不推荐或修改求解配置。

## 使用

在仓库根目录运行，`<COMSOL_ROOT>` 为包含 `bin/win64` 的 Multiphysics 安装目录：

```powershell
python src/flowpilot/solve_baseline.py --comsol-root '<COMSOL_ROOT>' --output-dir outputs/baseline-solves/run-001 --runs 5 --timeout 300
```

需要 COMSOL 6.3、可用许可证及相应模块。入口只接受 SHA-256 与 manifest 基准一致的模型；可用 `--model` 指定同一模型的另一路径。未提交修改或异常模型会在启动 COMSOL 前被拒绝。

- `--runs` 为 1–10 的整数，默认 5；串行运行，每个进程使用 2 个计算线程。
- `--timeout` 为每次编译或批处理的超时秒数，不是整组运行预算。
- 每次必须使用新输出目录；已有文件、目录和符号链接均不覆盖。
- 每次重新复制原模型并启动独立进程，用 `clearSolutionData()` 清除保存解，检查 `isEmpty()`，再调用原有 `sol1.runAll()`。不重建研究或更改求解器设置。
- 求解完成后检查解存在，导出六项指标，保存独立的 `solved.mph`。原始基准始终不保存，运行前后检查源文件和副本哈希。

## 输出与失败处理

```text
run-001/
  BaselineSolve.java / .class / compile.log
  run-01/ ... run-05/
    input.mph / solved.mph
    batch-console.log / batch.log / result.json
  summary.json / report.md / run.json
```

只有唯一且顺序正确的“已清解—指标—已完成”标记、非空编译产物、原生日志、求解模型副本和有限数值同时满足要求，才接受一次运行。退出码 0 本身不是成功证明。

每次核对正向流量、质量守恒、速度范围、壁面速度、反向速度、正压降及求解器错误；六项指标与原历史基准的相对偏差不大于 `1e-5`，分母下限为 `1e-12`。整组还检查版本一致及相对首次求解的偏差。阈值用于该固定基准，不能直接推广到其他工况。

异常时立即停止后续运行，保留已有日志和已验证的 `result.json`；不生成成功的整组摘要。`run.json` 记录 `failed` 或 `cancelled`、失败阶段、当前次数及已通过次数。超时或用户中断会终止本工具启动的进程树，不终止其他 COMSOL 会话。

原始日志保留原始字节，可能采用本机中文代码页；JSON 完成标记为 ASCII，不依赖日志语言。日志可能含机器、路径或许可证信息，**不要直接上传原始日志**。当前仅采集原始日志和 API 指标，不自动推断非线性迭代数、自由度或内存峰值；GUI 对照仍待完成。

## 本机真实结果

COMSOL 6.3.0.290、2 线程，连续 5 次清解后求解全部完成。下表耗时为本机观测，不是跨机器性能基准：

| 次数 | 求解调用耗时（s） | 整个批处理进程耗时（s） |
|---:|---:|---:|
| 1 | 3.536 | 12.666 |
| 2 | 3.429 | 13.137 |
| 3 | 3.269 | 12.718 |
| 4 | 3.353 | 12.906 |
| 5 | 3.332 | 13.145 |

`solve_seconds` 由 Java 单调计时器围绕 `runAll()` 测量；`process_seconds` 包括启动、加载、求解、指标提取和保存，不能与 GUI 中四舍五入的纯求解时间混用。

- 相对质量误差约 `8.29857166e-4`；最大速度约 `0.0144265456 m/s`；压降约 `0.0775840421 Pa`。
- 六项指标相对首次运行的最大偏差约 `7.22e-16`，与历史基准一致；API 的求解错误和警告字符串均为空。已有入口/出口弃用提示不因此消失，详见 `GUI_REVIEW.md`。
- 第五次保存的求解副本再连续只读加载两次，零诊断项，清单与原基准一致。
- 六个原始模型的 SHA-256 仍与 manifest 一致；五个异常模型未求解。

版本化证据为 [五次求解摘要](../data/fixtures/baseline_solve_suite.json)，含每次原始指标、清解证据、耗时、工程检查、源码/参考记录哈希及本地日志哈希；不包含原始日志或本机绝对路径。离线测试会重新计算这些检查，不能据此宣称 CI 执行了 COMSOL。
